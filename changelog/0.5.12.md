## The skill is now answer-me-with-any

The skill and the Claude Code plugin are named `answer-me-with-any`, and they install from `reeschan/answer-me-with-any`:

```bash
npx skills add reeschan/answer-me-with-any
/plugin marketplace add reeschan/answer-me-with-any
/plugin install answer-me-with-any@answer-me-with-any
```

- The skill folder is `skills/answer-me-with-any`, so a new install goes to `~/.claude/skills/answer-me-with-any` or `~/.agents/skills/answer-me-with-any`.
- The commands are `/answer-me-with-any config` for the skill, and `/answer-me-with-any:config` and `/answer-me-with-any:clean` for the plugin. The always-on reminder is `[answer-me-with-any always-on]`; update the rule in your rules file when you reinstall.
- The update notice on a page gives `npx skills update answer-me-with-any -y` or `claude plugin update answer-me-with-any@answer-me-with-any`, and its links go to https://github.com/reeschan/answer-me-with-any. The update check reads the version from the same repository.
- **An install under the old name keeps working until you reinstall it.** It keeps its folder, its commands and its update source. To move to the new name, remove the old copy and install again with the commands above.
- Not changed: the data folder `~/.answer-me-with-html` (and `AM_HOME`), the `am` and `answer-me-with-html` commands of the package, and the theme catalog at answer-me-with-html.com.

## skill 改名为 answer-me-with-any

skill 和 Claude Code 插件改名为 `answer-me-with-any`，从 `reeschan/answer-me-with-any` 安装：

```bash
npx skills add reeschan/answer-me-with-any
/plugin marketplace add reeschan/answer-me-with-any
/plugin install answer-me-with-any@answer-me-with-any
```

- skill 目录是 `skills/answer-me-with-any`，新安装会放在 `~/.claude/skills/answer-me-with-any` 或 `~/.agents/skills/answer-me-with-any`。
- 命令是 skill 的 `/answer-me-with-any config`，以及插件的 `/answer-me-with-any:config` 和 `/answer-me-with-any:clean`。高频模式的提醒是 `[answer-me-with-any always-on]`；重新安装时，把规则文件里的规则也改过来。
- 页面上的新版本提示给出 `npx skills update answer-me-with-any -y` 或 `claude plugin update answer-me-with-any@answer-me-with-any`，链接指向 https://github.com/reeschan/answer-me-with-any。检查新版本也从这个仓库读取版本号。
- **用旧名字装的副本在重新安装前照常可用。** 它的目录、命令和更新来源都不变。想换成新名字，先删掉旧副本，再用上面的命令重新安装。
- 没有改的：数据目录 `~/.answer-me-with-html`（以及 `AM_HOME`）、包里的 `am` 和 `answer-me-with-html` 命令，以及 answer-me-with-html.com 上的主题目录。
